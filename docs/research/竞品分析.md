# AyTool 竞品分析

> 整理日期：2026-08-19
> 证据来源：Phase 0 SERP 实测（30+ 关键词，美国出口 + DuckDuckGo ph-en 区域复核，见《SERP验证报告-phase0.md》）+ Flippa 在售站结构分析。每个站后标注它在哪些目标词的前排出现。
> 用法：开发前按 §7 侦察清单逐个过一遍功能细节；上线后每季度回访一次头部直接竞品。

---

## 一、直接竞品：独立计算器/工具站（同赛道同模式，主要对手）

| 站点 | 占位的目标词 | 强项 | 弱点（我们的机会） |
|---|---|---|---|
| **sweldongpinoy.com** | 13th month pay calculator | 老牌（多年权重）、菲律宾人认知度最高的工资计算器品牌 | UI 陈旧（十年前工程师审美）、无缴费表内容层、无 GEO 布局 |
| **sweldoph.com** | night differential（**一站双位**：指南页+计算器页） | 「指南+计算器」双页模式的验证者，覆盖面较新 | 品牌新、页面单薄；我们用同模式 + 更深内容对打 |
| **suweldocalculator.com** | night differential / holiday pay 相关文章 | 有博客层 | 工具体验一般 |
| **taxcalculatorphilippines.com** | sss contribution table / philhealth table / take-home | **用 take-home 计算器反向吃缴费词群**（我们 take-home 页的直接对标） | EMD 域名无品牌感；广告多 |
| **incometaxcalculator.ph** | philhealth contribution table（第 1 位） | .ph 本地后缀 + EMD | 单薄，靠域名吃词 |

**判断**：这一档没有一个「工具好用 + 内容深 + 干净无广告」三者兼备的玩家——这正是 AyTool 的定位空隙。

## 二、内容农场/表格站（靠年更表格吃流量，无工具）

| 站点 | 占位的目标词 | 特征 |
|---|---|---|
| **philpad.com** | sss table / philhealth table（多词前排） | 经典菲律宾独立博客，年更表格文章，广告变现 |
| **requirementph.com** | sss table / philhealth table | 站群式「requirements + table」农场 |
| **howtoquick.net** | sss table（2018 年老文持续更新） | 老文吃存量权重的典型 |
| **nationaliddigital.ph** | sss table 2026（PH 区第 2 位） | 政务信息农场，蹭 national ID 起家扩到缴费表 |
| **pesohub.ph** | sss contribution guide | 较新的政务/金融信息站 |
| **knowmygovt.com** | philhealth table | 多国政务信息模板站 |

**判断**：它们证明了「年更表格页」的流量成立，但**全都没有交互计算器**——我们的表格页 = 它们的表格 + Salary Lookup + 计算器互链，形态上直接压制。它们的年更节奏（1 月新表发布后谁先更新谁吃流量）是要学的运营纪律。

| 站点 | 类型 | 占位的目标词 |
|---|---|---|
| **sprout.ph** | HR SaaS | 13th month / holiday pay / night differential（多词前排，内容质量高） |
| **nextpay.ph** | 薪酬 fintech | 13th month + holiday pay calculator |
| **kamiworkforce.com** | HR SaaS | sss+philhealth+pagibig 三表合集 / night diff |
| **eezi.com / penbrothers.com / manilarecruitment.com / oysterhr.com / incorp.asia / forvismazars.com** | HR/招聘/会计服务 | holiday pay / night diff / back pay 的长文指南 |
| **moneymax.ph / digido.ph / homecredit.ph** | 金融媒体/借贷 | back pay / 13th month 文章 |
| **laborlaw.ph** | 劳动法内容站 | holiday pay / 13th month computation（法律条文向权威） |
| **respicio.ph / duranschulze.com** | 律所内容 | back pay 法律解读 |
| **jobstreet / bossjob.ph / cloudcfo.ph / scouttalented.com** | 招聘/服务 | back pay / 13th month 边角词 |

**判断**：这一档内容质量不低但**全是文章、几乎无工具**（holiday pay / back pay 前排零计算器 = 我们最干净的切入缺口）。它们做内容是为了获客卖 SaaS/服务，不会和我们卷工具体验；SEO 上打不过它们的域名权重时，靠「工具意图词」绕开正面（calculator 词 vs computation 文章词）。

## 五、风险区玩家（反面教材，只观察不模仿）

| 站点 | 模式 | 为什么不学 |
|---|---|---|
| **philhealthportal.com** | 蹭官方词域名 + 10 篇文章 6.5 万月 UV（Flippa 在售 $19,800） | 落在 PhilHealth 官方打假公告类别内（仅 philhealth.gov.ph 为官方），流量随时归零——低价甩卖本身就是风险定价 |

## 六、官方站（SERP 占位者，不是竞品是链接对象）

sss.gov.ph（sss table 词 PH 区第 1）、philhealth.gov.ph、pagibigfund.gov.ph、dole.gov.ph / bwc.dole.gov.ph、prc.gov.ph、nbi.gov.ph。
**与它们的关系**：每页引用 + 外链它们（E-E-A-T 与红线要求）；官方占第 1 位是常态，我们抢的是「官方页难用/无计算器」留下的 2–5 位。

## 七、开发前侦察清单（写代码前逐个看一遍，各 10 分钟）

1. **sweldongpinoy.com** 的 13th month 计算器：输入项、结果展示方式——我们要在同样简单的前提下多给 Breakdown
2. **taxcalculatorphilippines.com** 的 take-home 计算器：四险一税的拆解顺序与默认值处理
3. **sweldoph.com** 的 night differential 页：指南+计算器双页的内链方式
4. **philpad.com** 最新 SSS 表格文章：表格呈现结构、更新日期展示位置（学它的年更运营，超它的表格交互）
5. **sprout.ph** 的 holiday pay 指南：内容深度基线（我们的 FAQ 至少要覆盖它答过的问题）
6. **lisensyaprep.com** 的 PRC 日历页：筛选交互
7. 以上全部记录：是否有结构化数据、页面重量、广告密度——用于确认我们的性能与干净度优势可感知

## 八、差异化总结（一句话版）

竞品三分天下：**独立工具站（工具旧）、表格农场（无工具）、B2B 内容（无工具且不卷体验）**——没有人同时做到「计算器好用 + 表格全 + 官方溯源 + 极致性能 + 零广告 + GEO 就绪」。AyTool 的打法不是发明新需求，是**在已验证的需求上把六件事同时做对**。
