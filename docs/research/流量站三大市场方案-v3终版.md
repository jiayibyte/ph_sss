> 定稿日期：2026-08-19（v3.1：同日完成 Phase 0 SERP 全量验证后更新）

> 核心原则：**先验证搜索需求和页面模型，再扩量**；Flippa 数据用于「发现选题」，战略结论只采信可验证证据。

## 一、证据与方法论

### 1.1 双轨数据方法（两版合并的正确姿势）

| 轨道 | 用途 | 做法 |
|---|---|---|
| **批量抓样**（v1 方法，保留） | **选题发现**：哪些模式有人做出流量 | Flippa v3 API 按 `property_type=website` 分页抓样去重（2026-08-19 抓样 904 条，全站约 4,600 条），筛 `uniques_per_month ≥ 30k` 得到候选池 |
| **逐条证据分级**（v2 方法，采纳） | **结论采信**：哪些案例能当证据 | 点开 listing 核对：A 级 = Data Verified 且接 GA/AdSense；B 级 = Verified Listing 但关键数字卖家填写；C 级 = 仅卖家文案。**战略结论只用 A/B 级，C 级只当线索** |

Flippa 能回答的问题：「哪些网站模型在真实市场中有人做出来、有流量、能成交？」
Flippa 不能回答的问题：「某国某关键词现在竞争低不低？」——这必须用 SERP 人工核查（见第八章 Phase 0）。

### 1.2 已知偏差（做结论前必读）

- **幸存者偏差**：在售站不是同期所有新站的随机样本；站龄 ≠ 第几个月达标。「27/904 且过半是 2024–2025 新站」只能证明**存在性**（市场上存在 1–2 年建站达到 3 万月 UV 的真实案例），不能证明「12–18 个月达标是大概率事件」。
- **指标混淆**：Flippa 的 PV / Monthly Users / uniques 与 GSC organic clicks 差异可能极大（Motoristo：18.6 万 PV/月 vs 卖家自述仅约 8,500 organic visitors/月）。
- **来源构成**：「verified traffic」≠ Google 自然流量（247 Calculator 约 90% 流量来自非 Google 渠道）。
- **Seller Location ≠ 流量国家**：卖家聚集地（如巴基斯坦站群）只说明「谁在工业化复制什么公式」，这本身是**避开红海选题的有效信号**（菜单价格站已被站群批量复制 → 避开；政务计算器尚未 → 可试）。

### 1.3 核心案例库（合并后，含证据等级）

| 案例 | 证据等级 | 关键数字 | 对本项目的意义 |
|---|---|---|---|

| birthdaymarathiwish.net | **B**（平台验证流量） | 月 UV 5.2 万，2025 年建站，要价 $1,350 | 区域语言小站可快速起量的存在性证明 |

### 1.4 五条可采信规律

- **A. 工具站模型成立**：明确输入 → 即时结果 → 长尾查询 + 重复访问，维护成本低。
- **B. 页数不是核心变量**：页面是否对应真实搜索需求 > 模板规模（ZEN 反例）。
- **C. 垂直 > 万能大全**：先做清晰主题集群，验证后再扩，不做「5000 个泛工具」。
- **D. Flippa 数字必须分级**：PV / uniques / organic 严格区分，来源构成必查。
- **E. 新站能起量，但没有固定时间表**：不承诺「X 个月必达」，用 30/60/90 天门槛代替。

## 三、方向一：南非 MzansiCheck（首个验证市场）

### 3.1 定位

> **South Africa calculators & official-process guides**——本地计算器 + 政府流程解释 + 时间节点信息页。帮用户**计算、理解、找到正确官方入口**，不替代政府系统。

事实修正：SASSA 官方口径是超过 1800 万人领取**各类**社会补助（儿童金、老人金等合计），SRD 只是其中一类。SRD 因逐月重审、发放日每月由官方公布，「按月查询」行为真实存在，但规模按 SRD 领取者（数百万级）估算，不按 1800 万。

**红线（硬性）**：明示 Independent / Unofficial Guide；不收身份证/银行/手机号等敏感信息；不做形似官方 status checker 的交互，真实查询动作一律跳官方站；不用官方 logo、政府配色仿制、误导性域名（sassa-xxx 一律不注册）。Google spam policy 明确打击冒充官方服务的 imposter site。

### 3.2 MVP：先 25–35 页（不是 100 页）——⚠️ Phase 0 实测后权重已重排

Phase 0 关键发现：**SASSA 是全场最拥挤的簇**（前排被 allsassa/sassacheck 等含 sassa 的红线式站群占领），而 UIF/APS/薪资计算器前排全是可超越的独立小站——**主引擎从 SASSA 换成 UIF + APS**。

**A. 高意图计算器（8–10 个，主引擎）**：
- **UIF 组（🟢 主推）**：UIF 赔付估算、UIF 缴费、按薪资示例长尾页（"earn 8000 UIF" 类 SERP 实测无人防守）——ZA 区复核确认前排 6/7 为独立小站
- **APS 组（🟢 主推）**：APS 总计算器 + **per-university 长尾**（自动补全实测 wits/uj/uct/nwu/cput/uwc 各是独立搜索词）
- **薪资组（🟢）**：税后到手工资（前排全独立站）、时薪↔月薪换算、加班费；PAYE 主词 🟡（Sage/TaxTim 在位），做 reverse 计算等差异化角度
- VAT 计算器（补充）

**B. 官方流程指南（8–10 页，次推）**：NSFAS 申请状态官方查询（🟢 SERP 有 Medium/FB 弱位）/ NSFAS 申诉 / UIF 申领状态 / SASSA SRD 官方查询步骤 + 银行信息修改（🟡 内容缺口真实但属站群灰区，只做指南页不扩簇）/ SARS 报税入门 / 驾照更新清单

**C. 时效页（5–8 页）**：SASSA payment dates 2026–2027（🟡 自动补全实测逐月分裂成独立搜索词，月度复购行为证实；官方每月发布新日期，按官方节奏同步属真实新鲜度）/ NSFAS 申请窗口 / matric「how to check」指南（⚪→🟡 ZA 区复核：主词政府占前 2 位属正常，uni24/southafricaportal 等独立站填满中段，指南位开放）/ 大学申请截止日历 / 报税季日期

**D. 信任页**：About / Editorial Policy / Data Sources / Disclaimer

## 六、移动端与页面标准

**Statcounter 2026-07 实测**：印度 66.4% / 南非 58.5% / 菲律宾 60.8% 移动端。三国全部 mobile-first；**南非 PC 占四成**（薪资/税务计算器有办公场景）、**印度图片/PDF 工具 PC 占比高**（网吧填表），这两处 PC 体验不能敷衍。同时注意：我们的目标人群（补助金领取者、sarkari 考生）比全国大盘更偏手机。

**设计标准**（启发式 + 硬指标，去掉「100KB 否则被 Google 惩罚」这类不存在的规则）：
1. 硬指标 = **Core Web Vitals 全绿**（真实设备 + 弱网测试），页面尽量轻是达标手段不是教条
2. 计算器按拇指设计：大输入框大按钮、`inputmode="numeric"`、结果即时显示免提交
3. 缴费表/日历小屏用卡片式或横滑容器
4. JS 不阻塞首屏；无登录、无敏感信息存储
5. 验收以手机端体验为准（Google 对三国均为移动优先索引）

## 七、SEO 红线（Programmatic 纪律）

## 八、90 天验证计划（执行主线）

### Phase 0：SERP 实证 ✅ 已完成（2026-08-19，详见《SERP验证报告-phase0.md》）

**执行内容**：30+ 关键词逐个实搜（美国出口）+ 4 个主簇本地区域复核（DuckDuckGo za-en/in-en/ph-en 区域参数，Bing 索引二次信号）+ 5 个主簇需求量级信号核验（Google 自动补全广度；Google Trends 匿名接口限流未取得曲线）。

**总判定：19 🟢好打 / 8 🟡拥挤 / 3 🔴避开**。跨市场规律：
1. 所有 🟢 词的前排都已有独立小站存活——模型成立是现状不是假设

3. 本地语言是穿甲弹：英文词锁死的主题，印地语长尾巨头全体缺席
4. 流量最大簇 = 最灰簇：SASSA status（ZA）与 NBI clearance（PH）均被仿官方域名站群占领——做旁边绿区，不打正面灰区
5. 「文章多、工具少」= 最干净切入信号（PH holiday pay / back pay 前排零交互工具）

**本地区域复核（za/in/ph 区）**：uif calculator 前排 6/7 独立站 ✅；byaj calculator 前排 100% 印地语小站 ✅；sss table 官方第 1 + 独立站占 2–5 位 ✅；matric 主词政府占前 2（正常），uni24 等独立站填中段，「how to check」指南位开放 ✅。

## 九、结论置信等级

**高置信**：工具/计算器模型有真实资产案例；批量铺页不保证流量；Flippa 各流量指标必须分级采信；仿官方政务 portal 高风险；ccTLD 是明确地域信号、源站位置不是核心变量；三国均 mobile-first（印度 66.4% / 南非 58.5% / 菲律宾 60.8%，2026-07 实测）。
**Phase 0 后新增高置信**：UIF/APS/薪资计算器（ZA）、byaj/印地语长尾（IN）、缴费表/薪资计算器/OEC（PH）竞争可打——SERP 实测前排为独立小站或弱质结果，并经本地区域参数复核；SIP/英文 SSY/贷款金额页/PAYE 主词被商业巨头锁死应避开；SASSA status 与 NBI clearance 为仿官方站群区应降级；SASSA payment dates 的月度复购搜索行为成立（自动补全逐月分词直证）；「英文锁死的主题印地语长尾巨头缺席」经同主题对照实测成立。

**中置信**：南非适合做首个英语 MVP（Phase 0 后证据增强：主簇全绿 + 英语零摩擦）；印度区域语言工具扩张空间更大；菲律宾 payroll/办事指南可测试；巴基斯坦站群聚集的选题（餐厅菜单价格类）应避开；主簇需求量级足以支撑日均 1000 访问（自动补全满层建议树 + 同类站验证流量锚点，非精确搜索量）。

**未被证明（禁止写进对外结论）**：任一市场 6–10 个月必达 1000 自然访问/天；C 级证据的具体流量/收入数字；各词的精确月搜索量（Trends 匿名接口限流，Keyword Planner 无权限——不阻塞 Phase 1，有权限时回补）；美国出口 SERP 与真实本地 Google 排名的位次差异（域名构成经 DDG 区域参数复核，位次细节未经本地 IP 复核）。
